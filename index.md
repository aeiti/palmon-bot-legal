# Palmon Bot

An unofficial Discord bot for *Palmon: Survival* communities — Palmon and trait
lookups, event schedules, and gift codes.

This site hosts the bot's public policies:

- **[Terms of Service](terms-of-service/)** — what the bot is, what the game
  data is worth, and the rules for using it.
- **[Privacy Policy](privacy-policy/)** — what the bot stores (Discord ID
  numbers and your server's settings), what it does not, and how to have it
  removed.

Palmon Bot is a fan-made project. It is not affiliated with, endorsed by, or
connected to the developers or publishers of *Palmon: Survival*.
